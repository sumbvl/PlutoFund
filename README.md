
## PlutoFunds

A fintech landing page built with React, Tailwind CSS, and React Router. Showcases payment products with a hero section, stats, features, testimonials, and a mock login/register flow.

## Features
- Responsive landing page containing hero, stats, features, billing section, testimonials, CTA, footer
- Login & Register pages with client-side validation
- Mock authentication using a hardcoded user array (frontend-only demo, no backend)
- Custom alert notification on successful registration
- Client-side routing with React Router
  
## Tech Stack
- React
- Tailwind CSS
- React Router DOM
- React Icons
  
## Getting Started
1. bash
2. git clone https://github.com/sumbvl/plutofunds.git
3. cd plutofunds
4. npm install
5. npm run dev
